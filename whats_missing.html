Backups, keyboard shortcuts & local storage

Collections, uploaded images, settings and scores stay in this browser on this device. They do not sync automatically. Export a backup before clearing browser data.

Collection backups embed uploaded pictures. URL pictures are embedded when the image host allows it; otherwise the backup keeps the original URL and needs internet. This HTML includes all code, sample art and synthesized audio. Download it for offline use with uploaded pictures; the hosted page itself is not installed or cached for offline navigation.

Game shortcuts: Space start/pause/resume · H hide · R reveal all · N next round · F fullscreen. Use the on-screen Dashboard button to exit.
